Principles (what makes it premium)

1. Glass over busy backgrounds

Use backdrop-filter: blur(12–22px) + semi-opaque tint (10–30%) + 1px rgba(255,255,255,0.08) border. Keep blur 10–20 sweet spot; busier backdrops need more blur [uxpilot.ai]. Layer a soft gradient behind glass (violet/navy orbs) so glass has something to refract — not high-frequency noise.

2. Cards must breathe

Internal padding 16–24, title 14–16 semibold, meta 10–12 muted, gap 8–12 between title/body, 16–32 between cards. Max 2–3 font sizes per card. [thehangline.com] Don’t shrink desktop cards on mobile — restack 2→1 column.

3. Hierarchy in 2 seconds

One card = one concept. Whole card clickable (Fitts), subtle shadow = affordance, lift on hover: translateY(-2px) + shadow 12–24px [uxplanet.org + layoutscene]. Headline dominant, supporting text 1–2 lines, truncate >90 chars.

4. Consistency is the system

Same radius, same shadow, same padding per card type. Define tokens, make variants (metric, product, log) in Figma Variants. Test light/dark + mobile + WCAG AA (4.5:1).

Sources: glassmorphism blur/border/opacity best-practices [dev.to + uxpilot.ai + medium.com], card spacing/width/hover [thehangline.com, bricxlabs.com, uitop.design], Montserrat pairing [madegooddesigns.com]. Full citations in DESIGN_GUIDE.md.

Rules

Load max 3 weights: 400,600,700,800 (each +20–30KB). Use 600–700 for headings, 400–500 for body. Line-height 1.4–1.6 body, 1.1–1.3 titles. Ratio 2:1 heading:body. Never go <12px for body.

Pair: Montserrat alone is premium geometric — no need for Merriweather/Inter in this dark glass system.

Spacing / Radius / Shadow / Blur

Space: 4 / 8 / 12 / 16 / 20 / 24 / 32 (4pt grid) — card pad 16–20, gap 12–16
Radius: sm 8 • md 12 • lg 16 • xl 20 • pill 999
Shadow: card 0 10 28 -18 rgba(0,0,0,.9) • modal 0 28 80 rgba(0,0,0,.65)
Blur: card backdrop 12–16, modal 22 + saturate 1.15; limit 5–8 blurs/page, will-change:transform; transform:translateZ(0)

Do / Don’t

Do: 12–16 gutter even when dense, use background contrast not just space to separate; elevate on hover 2–4px. Don’t: heavy shadow everywhere, 4+ buttons per card, mixed widths in one grid, shrinking desktop card on mobile.

How to use this file for any revamp

  1. Start from tokens, not pixels. Import :root vars from this file into Admin.html <style> — bg, text, border, radius, shadow, blur. Never hardcode a color.
  2. Pick a component shell. Need a card? Copy .lpv-card + .lpv-card--variant + __accent/head/icon/badge/value/foot. Need a pill? .lpv-badge / .pill. Keep structure identical — only swap accent/badge.
  3. Mont + SVG only. Check font-family: Montserrat everywhere, replace any emoji with inline <svg viewBox="0 0 24 24"> from this file.
  4. Respect spacing. Card pad 14–16, head 14/12/17, value 14/17, foot 10/14/17. Gap 8–12 inside, 14 between cards. Use gap: var(--space-*).
  5. States: :hover → translateY(-1px) + border 0.14 + shadow, :active → translateY(0), :focus-visible → 2px outline, .copied → green border. Ensure 44px min tap.
  6. Blur budget: max 5–8 blurred surfaces per page, will-change:transform on animating orbs only, bake static blur into image.
  7. Test: dark + light (if any), mobile 1-col, WCAG 4.5:1, screen reader: icon has aria-hidden, value is real text, copy button has aria-label.

Detailed checklist + before/after + citations → DESIGN_GUIDE.md (same folder). Open this HTML in browser, inspect, copy.
